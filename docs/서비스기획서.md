# 냉털셰프 서비스 기획서

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 냉털셰프 (냉장고 털이 셰프) |
| 한 줄 소개 | 냉장고에 남은 재료로 지금 만들 수 있는 메뉴를 AI가 추천해 주는 서비스 |
| 목적 | 메뉴 고민 시간을 줄이고, 남은 식재료를 버리지 않고 활용하도록 돕는다 |
| 타겟 사용자 | 자취생, 1인 가구 직장인, 장보기가 번거로운 사람 |
| 제공 가치 | 재료만 입력하면 몇 초 안에 메뉴 2개와 조리 순서를 확인할 수 있다 |

## 2. 페이지 / 섹션 구성

한 페이지(원페이지) 구조이며, 상단 고정 메뉴의 앵커 링크(`#home`, `#how`, `#recipe`, `#faq`)로 섹션 간 이동한다. 모바일(768px 이하)에서는 햄버거 버튼으로 메뉴를 열고 닫는다.

| 섹션 | 내용 |
|---|---|
| 1. 홈 (Hero) | 서비스 소개 문구, "재료 넣어보기" 버튼 (레시피 섹션으로 이동) |
| 2. 이용 방법 | 재료 입력 → 조리 시간 선택 → 레시피 확인, 3단계 카드 |
| 3. 레시피 만들기 | AI 기능: 입력 폼과 결과 표시 영역 |
| 4. FAQ | 양념 입력 여부, 재료가 적을 때 등 자주 묻는 질문 4개 |

## 3. 핵심 기능

1. **AI 레시피 추천:** 재료와 조리 시간을 입력하면 메뉴 2개를 추천
2. **섹션 네비게이션:** 상단 메뉴 클릭 시 해당 섹션으로 부드럽게 스크롤
3. **반응형 레이아웃:** 데스크톱, 태블릿, 모바일에서 깨지지 않는 화면
4. **다크 모드 (보너스):** 기기 설정에 따라 자동 적용

## 4. AI 기능 설계

### 입력

| 항목 | 형식 | 조건 |
|---|---|---|
| 재료 | 텍스트 (쉼표 구분) | 필수, 200자 이내 |
| 조리 시간 | 버튼 선택 | 10분 이내 / 20분 / 30분 이상 (기본값 20분) |

### 출력

- 추천 메뉴 2개
- 메뉴별 사용 재료, 있으면 좋은 재료, 조리 순서 3~5단계

### 처리 흐름

```
사용자 입력 → JavaScript 1차 검증 → fetch('/api/generate') POST 요청
→ Python 함수 2차 검증 → Gemini API 호출 (API 키는 환경 변수)
→ JSON 응답 → 화면에 결과 또는 안내 문구 표시
```

### 실패 처리 기준

| 상황 | 감지 위치 | HTTP 코드 | 사용자 안내 문구 |
|---|---|---|---|
| 빈 입력 | 프론트 + 백엔드 | 400 | 재료를 하나 이상 입력해 주세요. |
| 200자 초과 | 프론트 + 백엔드 | 400 | 재료는 200자 이내로 입력해 주세요. |
| 식재료가 아닌 입력 | AI 응답 (NO_INGREDIENT) | 422 | 입력하신 내용에서 식재료를 찾지 못했어요. |
| API 키 누락/오류, 모델 이름 오류 | 백엔드 | 500 | 서버 설정 오류예요. |
| 요청 과다 (무료 등급 한도 초과) | AI API 429 | 429 | 요청이 많아요. 1분 뒤 다시 시도해 주세요. |
| AI 서버 오류 | AI API 4xx/5xx | 502 | 레시피를 불러오지 못했어요. 잠시 후 다시 시도해 주세요. |
| 응답 지연 | 백엔드 20초 / 프론트 25초 | 504 | 응답이 지연되고 있어요. 잠시 후 다시 시도해 주세요. |
| 네트워크 끊김 | 프론트 | - | 네트워크 오류가 발생했어요. |

## 5. 테스트 케이스

| 구분 | 입력 | 기대 결과 |
|---|---|---|
| 정상 | 계란, 김치, 밥, 대파 / 10분 이내 | 김치볶음밥 등 메뉴 2개 표시 |
| 빈 입력 | (빈 값) | "재료를 하나 이상 입력해 주세요." |
| 식재료 아님 | 노트북, 의자 | "식재료를 찾지 못했어요." |
| 긴 입력 | 200자 초과 | 글자 수 제한 안내 |

## 6. 보안 및 운영 고려

- API 키는 Vercel 환경 변수에만 저장하고, 코드·README·스크린샷에 노출하지 않는다.
- AI는 Google Gemini API 무료 등급을 사용한다. 무료 등급은 분당·일일 호출 제한이 있으므로, 요청 중 버튼을 비활성화해 중복 호출을 막고 입력 길이와 응답 길이를 제한한다.
- 키 유출이 의심되면 즉시 폐기·재발급하고 커밋 이력에서 제거한다.
